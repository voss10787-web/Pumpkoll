# Pumpkoll

Betongleveranser, lossningstider och pumpstatistik.

Publicera med GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

Öppna sidan i Safari och välj Dela → Lägg till på hemskärmen.

Data sparas lokalt i webbläsaren. Exportera från Statistik för säkerhetskopia. Om du använt den tidigare adressen: exportera där och importera på GitHub Pages-adressen.
